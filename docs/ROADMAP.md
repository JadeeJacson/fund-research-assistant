# v2.1 实施与验收路线

本分支按以下阶段实施。完成状态以 `PROJECT_STATUS.md` 和测试结果为准，不把目标写成现状。

1. 规范与规则配置：产品需求、三仓模型、数据契约、UI 契约；
2. v2 工程底座：`/api/v2`、独立 SQLite、Alembic 基线、分层服务；
3. 真实数据与证据：累计净值、同类历史、申赎事实、公告候选和数据门；
4. 组合与 OCR：完整快照、可修改计划金额、草稿校对和归仓覆盖；
5. 同类与替代：月度候选缓存、最多 50 只同类、两次评估升级；
6. 决策与回放：优先级、持续交易日、最小动作、用户决定和冷却；
7. DeepSeek：本机配置、匿名 Evidence Pack、Schema 与引用校验；
8. 产品 UI：五页交互、响应式、状态和可访问性；
9. 验收与瘦身：单元/API/E2E、真实 Provider smoke、Windows 脚本、v1 清理。

不在 v2.1 范围：认证、多组合、后台定时任务、自动交易、商业实时数据和移动端主要操作体验。
