# 持仓快照与 OCR

持仓输入是“当前事实”，不是交易账本。每个快照保存日期、总市值、来源、完整性和持仓行；个人展示盈亏不参与基金质量。

截图上传后在本机 RapidOCR 处理，保存图片哈希、原始文本、置信度、问题和草稿行。解析器优先使用六位基金代码；代码未显示时，会把中文名称与本地基金目录进行保守匹配，必要时查询公开基金目录。名称截断、同名歧义或“余额宝”等未显示底层基金的产品保持未匹配，不猜测代码。文件类型、大小、图片完整性和重复哈希都会校验。

OCR 结果必须人工校对。只有用户明确勾选“这是当前全部持仓”的 complete 快照才能运行仓位评估；partial 快照永久不会自动升级。DeepSeek 不接收图片、OCR 文本或个人金额。

同一基金在一个快照中只能出现一次，一只基金只能归一个仓。OCR 匹配成功后按基金类型与组合职责自动归仓；已有持仓或用户覆盖优先于默认规则。用户仍可在确认草稿前修改，覆盖记录用于后续快照。

v2 不保存逐笔交易、成本、份额现金流、XIRR 或 TWR。
