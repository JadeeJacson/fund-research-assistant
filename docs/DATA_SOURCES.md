# 数据来源与质量

## 来源优先级

官方公告、基金合同和指数规则优先；AKShare 等聚合入口用于目录、净值、同类、费率/申赎和公告索引；普通新闻只能由用户手工添加为 B 级补充。

每条外部数据记录来源、数据对应日期、获取时间和质量状态。来源冲突或总回报无法核验时进入 limited/blocked，不静默覆盖。

## 净值和总回报

计算优先使用累计净值。只有单位净值时可以展示事实，但相对收益、质量和替代结论会被阻断。分红/拆分口径无法确认时不猜测复权。

QDII 额外展示净值日期、币种和海外休市/汇率/估值时差提示。应用不使用需要 Cookie 的接口。

## 缓存与失败

生产顺序是最新有效数据、已验证缓存并标陈旧、备用免费 Provider（未来扩展）、数据阻断。Fixture 只在测试或显式 demo 模式使用。

候选宇宙按 `月份 + peer_key` 缓存；每次对照重新检查候选的净值和状态。并发刷新最多 4 个，单个失败只阻断该基金。

## 公告

自动采集标题、日期、报告链接和内容哈希。聚合索引产生候选事件；只有用户核验原文或可验证的官方原文才允许触发硬风险。
