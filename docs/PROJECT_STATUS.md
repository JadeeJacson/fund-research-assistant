# 项目当前状态

更新日期：2026-08-24。默认产品入口为“基金仓位决策台 v2.1”，API 前缀为 `/api/v2`。

## 当前可运行能力

- FastAPI、SQLAlchemy、SQLite、Alembic 与分层服务；
- React Router、TanStack Query、Recharts 五页前端；
- 完整持仓快照、OCR 草稿、归仓覆盖与三仓比例；
- AKShare 净值、同类历史、申赎事实和公告索引；
- 数据质量、硬风险、基金质量和替代对照的独立评估规则；仓位比例与目标区间仅展示，不进入复核队列；
- 基金详情近一年累计收益率/回撤图，以及 1 月、3 月、1 年收益、波动、最大回撤、简化夏普和卡玛；
- 异步持久化评估、进度、局部失败、重启恢复和决定留痕；
- DeepSeek 配置、连接测试、前端手动 AI 解释、结果缓存和无 Key 降级；
- 用户主动触发的组合基金探索、持久化进度、同类有限扫描和多维候选展示；
- JSON 导出、SQLite 备份、Windows 安装和启动脚本；
- pytest、Vitest、Playwright 和生产构建。

## 明确边界

- 免费 Provider 的字段覆盖不等于商业数据库；规模、经理、基准或跟踪误差缺失会显示未知；
- AKShare 公告索引在原文未核验前只生成候选事件，不直接触发退出；
- 普通新闻仅支持手工添加，B 级新闻不能独立触发退出；
- 候选宇宙每月缓存；应用每次打开替代页或运行评估时刷新候选的最新净值与状态；
- OCR 对复杂支付宝版面仍需要人工校对，部分截图不会参与仓位判断；
- DeepSeek 只解释，不修改指标、仓位、动作或证据优先级。
- DeepSeek 不会随评估自动调用；用户在已完成评估中点击“生成 AI 解释”时才会调用或读取缓存。
- 基金探索只围绕当前完整持仓的同类基金筛选，至少两项显著改善才展示；它不是全市场排行榜，也不是买入建议。

旧 Streamlit/v1 源文件已移除；旧数据库保持只读备份，v2 不读取交易账本。当前 README 只描述 v2 已验收能力。
