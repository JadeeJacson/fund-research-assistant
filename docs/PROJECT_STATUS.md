# 项目当前状态

更新基线：MVP 实现分支，基于已合并的 v1 规范 PR #1。

## 结论

仓库现在同时包含：

1. 原有 Streamlit v0.1，作为回归参考；
2. React + FastAPI 本地网页 MVP，作为后续主线。

MVP 已经形成“候选研究—个人截图—组合适配—条件触发—AI 可选解释”的可运行闭环，但仍不是自动投顾、公开 C 端产品或完整量化平台。

## MVP 已完成

### 工程底座

- React、TypeScript、Vite；
- FastAPI、SQLAlchemy、SQLite；
- Alembic 初始迁移；
- 本地健康检查和统一校验错误；
- Windows 安装、开发和启动脚本；
- pytest、Vitest、Playwright 和 CI。

### 候选研究

- 六位基金代码；
- 已知份额与类型匹配；
- AKShare 公开净值；
- 离线演示回退并明确标记；
- 收益、波动和最大回撤；
- 2～3 个月和约 1 年报告；
- 操作状态、目标区间、有效期和风险提示；
- 主题基金仓位上限。

### 个人数据

- 候选、持仓和交易截图；
- RapidOCR 本地识别；
- 页面分类和已知基金匹配；
- 人工逐字段校对；
- 图片和交易去重；
- 确认前后数据隔离；
- 人工持仓与交易录入。

### 证据与 AI

- 手工 Evidence Pack；
- 来源、发布日期和可信等级；
- DeepSeek 可选结构化解释；
- Evidence ID 边界检查；
- AI 关闭或失败时确定性报告不受影响。

### 前端

- 总览；
- 候选研究；
- 截图导入；
- 持仓交易；
- 条件触发；
- 设置和 AI 测试；
- 所有可见按钮都有实际行为。

## MVP 已知限制

- 基金公开身份、费率、经理、基准、规模、持仓和估值尚未形成完整官方核验链；
- 自动公告与新闻采集尚未实现，Evidence Pack 需要人工录入；
- OCR 版面解析使用可审计规则，复杂截图仍需更多脱敏样例校准；
- 交易列表截图缺少确认详情时不能精确计算成本、XIRR 或 TWR；
- 组合相关性、穿透持仓、风险贡献和多情景压力测试仍需扩展；
- 本地触发器不是后台常驻任务；
- C 端认证、租户隔离和合规尚未实施。

这些限制不会通过空按钮或虚构结果隐藏。后续扩展继续以 `docs/ROADMAP.md` 为准。
