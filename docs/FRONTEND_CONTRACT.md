# 前端交互契约

五个路由页面：决策台、我的组合、基金详情、基金探索与替代对照、历史与数据。首次无持仓时只显示预算 → 录入/OCR → 确认完整快照 → 首次评估的引导，不显示虚假判断。

视觉令牌：背景 `#F5F1E8`、纸面 `#FFFDF8`、墨色 `#1F2A26`、绿色 `#247A5A`、警告 `#B7791F`、危险 `#B4473A`。颜色不是唯一语义，状态同时显示文字；数字使用表格数字。

主要验收尺寸为 1440×900 和 1024×768；低于 900px 折叠为顶部导航，移动端保证可读。

按钮必须映射真实 API，并有默认、加载、成功、空、校验失败、Provider 失败、禁用和重试状态。确认完整持仓、归仓覆盖和复核决定刷新后必须仍存在。

“生成 AI 解释”和“开始探索基金”只能由用户主动触发。AI 解释复用相同评估、模型和证据包的缓存；基金探索展示最多六只至少满足两项改善的同类候选，并同时展示反方、未知项和比较基准，不显示冠军或直接买入指令。

基金详情的主图使用后端计算的近一年累计收益率与同期回撤百分比，不以绝对净值制造“便宜”印象。风险指标注明窗口和口径；简化夏普按无风险利率为 0 计算，所有指标与个人持有盈亏分开展示。

概念方向参考 Codex 前端设计流程，交付前按 Vercel Web Design Guidelines 检查语义、键盘焦点、表单标签、对比度、响应式、加载稳定性和长文本。
