# v1 产品需求

## 1. 产品定位

本项目是面向个人实验资金的中国公募基金研究辅助系统。核心任务是：

1. 在购买前研究候选基金；
2. 导入个人候选、持仓和交易；
3. 结合基金本身、市场状态和个人组合；
4. 输出可解释、可追溯、有条件的操作建议；
5. 保存判断依据及其后续变化。

系统是研究和风险辅助工具，不是收益预测器、智能投顾牌照替代品或自动交易系统。

## 2. 用户与运行方式

- 第一阶段：单用户、Windows 本地运行。
- 使用方式：启动本地服务后在浏览器访问。
- 未来：保留部署为多用户 C 端网页的能力，但不得直接公开当前本地版。
- 数据范围：用户自行划出的实验资金；系统不管理实验资金之外的现金与生活资金。

## 3. 已确认约束

| 事项 | 当前决定 |
| --- | --- |
| 优先任务 | 购买前的候选基金研究 |
| 后续任务 | 已持有基金与组合分析 |
| 完整评价类型 | 指数基金、主动权益基金、普通债券基金 |
| 识别但暂不完整评价 | QDII、黄金/商品、FOF、公募 REITs 等 |
| 研究期限 | 2～3 个月；约 1 年 |
| 组合阶段性回撤参考线 | 约 10% |
| 短期仓位回撤参考线 | 约 10% |
| 行业/主题比例 | 系统产生动态建议区间 |
| 现金预留 | 不由系统强制管理 |
| 数据成本 | 第一阶段优先免费，必要时再引入小额付费数据 |
| 个人数据输入 | 候选、持仓、交易截图；支持人工校对 |
| AI | DeepSeek 文本 API；截图先由本地 OCR 转换 |
| 自动交易 | 不实现 |

10% 是历史与压力测试的风险参考线，不是未来最大损失保证。

## 4. 核心用户流程

### 4.1 候选基金

用户可以：

- 输入六位基金代码；
- 上传支付宝基金自选截图；
- 将已识别基金加入候选；
- 选择“2～3 个月”或“约 1 年”研究期限；
- 记录关注原因和计划资金；
- 对多只候选进行横向比较。

系统自动：

- 校验基金代码、名称和份额类别；
- 获取基金、基准、净值、费率、规模、经理和持仓；
- 获取官方公告、政策和可靠新闻；
- 计算基金类型专属指标；
- 生成研究报告和操作触发条件；
- 记录数据截止日期、来源和置信度。

### 4.2 个人持仓与交易

用户可以上传：

- 全部持有或资产构成截图；
- 收益明细截图；
- 交易记录列表；
- 必要的单笔交易详情；
- 多张连续或重叠截图。

系统必须：

- 本地 OCR；
- 识别截图类型；
- 生成候选、持仓快照或交易草稿；
- 标出低置信度、截断和缺失字段；
- 检测图片及记录重复；
- 允许逐字段编辑；
- 只有确认后才写入正式数据；
- 保存导入批次和人工修订来源。

### 4.3 研究报告

单基金报告至少包含：

1. 基金身份、份额和类型；
2. 数据来源、截止日期和质量；
3. 持有期与赎回限制；
4. 净值与总回报口径；
5. 绝对风险收益；
6. 基准与同类比较；
7. 基金类型专属评价；
8. 估值或市场状态；
9. 最新正式持仓与变化；
10. 基金经理、规模和费率；
11. 正面证据、风险证据、反方观点；
12. 组合重叠和适配；
13. 当前操作状态；
14. 建议仓位区间；
15. 买入、加仓、暂停、减仓或退出触发条件；
16. 建议有效期与失效条件；
17. 未知项和免责声明。

### 4.4 操作状态

- 数据不足；
- 暂不支持完整评价；
- 排除；
- 继续观察；
- 建仓候选；
- 小幅加仓候选；
- 继续持有；
- 暂停加仓；
- 减仓候选；
- 退出复核。

系统不得在数据质量、产品适配、持有期或风险门控未通过时输出强操作状态。

## 5. 条件触发

操作建议可以包含数值和持续时间，例如：

- 估值分位低于阈值并连续若干交易日；
- 回撤达到区间且风险假设未失效；
- 组合权重低于或高于目标区间；
- 波动率、相关性或压力损失超过阈值；
- 基准相对表现连续恶化；
- 经理、费率、指数规则或申赎条件变化；
- 公告或政策证据触发复核。

绝对单位净值不能单独作为“便宜”或“昂贵”的依据。

本地版在用户打开页面或主动刷新时检查；后续可使用 Windows 定时任务或部署后的后台任务每日检查。

## 6. 基金类型差异

### 指数基金

- 跟踪指数与编制规则；
- 跟踪误差和超额偏离；
- 费率、规模和流动性；
- 估值分位；
- 成分与行业集中度；
- 与组合现有暴露重叠。

### 主动权益基金

- 经理任职期与变更；
- 正确基准和同类；
- 风险调整收益；
- 持仓集中度、风格漂移；
- 规模变化；
- 回撤与修复能力。

不得用“基金自身 PE”简单代表主动基金估值。

### 普通债券基金

- 利率债、信用债、可转债和股票暴露；
- 久期、杠杆和信用信息可得性；
- 净值波动和回撤；
- 开放、锁定与赎回规则；
- 数据不足时不生成精确信用评分。

## 7. 非目标

v1 不实现：

- 自动登录支付宝；
- 获取 Cookie、密码或浏览器会话；
- 自动申购、赎回、转换或调仓；
- 高频和分钟级交易；
- 准确预测涨跌；
- 仅凭近期新闻追热点；
- 让 DeepSeek 生成核心金融数字；
- 让 DeepSeek 独立决定行业比例；
- 无来源的“金融专家”结论；
- 对所有基金类型套用同一模型；
- 公有云多用户直接上线。

## 8. 成功标准

v1 成功不以“建议赚了多少钱”定义，而以以下能力定义：

- 数据来源和时间可追溯；
- 公开数据与个人截图职责清楚；
- OCR 可校对、可去重、不会静默写错；
- 核心指标可通过固定样例复算；
- 操作状态由透明门控产生；
- 每个建议包含反方证据和未知项；
- API 或 AI 失败时仍能降级运行；
- 页面没有空按钮；
- 关键流程具有端到端测试；
- README 只描述已经实现和验收的能力。
