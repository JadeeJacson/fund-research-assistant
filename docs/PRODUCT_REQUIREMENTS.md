# 基金仓位决策台 v2.1 产品需求

## 定位

本地单用户、Windows 运行的个人基金仓位复核工具。用户通常每 2～3 天主动运行一次。系统不认证、不云部署、不定时监控、不执行交易。

计划投入金额由用户填写并可随时修改；仓位比例按最新完整持仓总市值计算，不预留现金。第一版只有一个组合。

## 三仓职责

| 仓位 | 比例带 | 中枢 | 观察窗 |
| --- | ---: | ---: | ---: |
| 流动防守仓 | 30%～50% | 40% | 60 个交易日 / 事件驱动 |
| 核心配置仓 | 30%～45% | 35% | 250 个交易日 |
| 卫星进攻仓 | 15%～30% | 25% | 55 个交易日 |

一只基金只能属于一个仓。默认按组合职责归仓，用户覆盖永久生效；集中度和行业暴露只形成提示，不拆仓。

## 结果契约

首屏总判断只有“无需调整信号”和“需要复核”。每条复核项独立保存 `data_quality`、`reason_type` 和 `proposed_action`。优先级固定为数据阻断、硬风险、质量恶化、替代对照。仓位比例及其目标区间只作组合展示，不进入评估、首屏三件事、复核队列或 AI 解释。

数据不足时不生成基金加减仓动作。确认复核只记录“同意 / 拒绝 / 稍后”和备注，不修改持仓。

## 支持范围

完整支持货币、同业存单指数、债券、国内指数/ETF/联接、主动权益/混合、QDII、黄金/商品和 FOF。REITs、分级/杠杆、私募和个券只显示事实。

系统不保存逐笔交易、XIRR/TWR、个人成本或“自买入以来亏损”规则。个人盈亏可保存在持仓展示字段，但不进入质量判断。

## 成功标准

- 无 DeepSeek Key 时确定性流程完整可用；
- Provider 失败时只用已验证缓存或明确阻断，绝不暗换演示数据；
- 每个结论可回放到持仓、数据日期、来源、规则版本和证据；
- 任意已确认金额的组合可复算三仓判断、质量复核、官方事件和替代对照；
- 不保存交易流水，不发送个人金额或截图，不执行交易。
