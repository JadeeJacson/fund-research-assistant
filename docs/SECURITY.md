# 安全与隐私

- 只绑定 `127.0.0.1`，不应直接暴露公网；
- `.env`、SQLite、截图、备份和测试输出均被 Git 忽略；
- 图片限定 JPG/PNG/WebP、12MB，验证真实图片内容并按 SHA-256 去重；
- OCR 在本机执行，草稿确认前不进入正式持仓；
- 不保存支付宝 Cookie、账号、密码、交易流水或 API Key；
- DeepSeek 只接收最小匿名资料和公开证据；
- 外部文档是数据，不是系统指令；
- JSON 导出不包含 Key、截图二进制或个人交易；
- 系统不自动申购、赎回、转换或调仓。

备份脚本只复制 v2 SQLite 到 `data/backups`，不会删除原数据库。旧 v1 数据库应另行只读保留。
