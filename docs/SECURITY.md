# 安全、隐私与合规边界

## 1. 威胁模型

第一阶段是单用户本地应用，但仍处理个人持仓、交易、截图和 API 密钥。主要风险：

- 图片或导出文件泄露；
- OCR/日志记录过多个人信息；
- 恶意或异常上传导致资源耗尽；
- 外部 Provider 或 AI 请求泄露不必要数据；
- 密钥进入仓库、日志或前端；
- 本地服务意外暴露到局域网或公网；
- 错误建议被误解为保证或自动投顾；
- 未来部署时沿用单用户假设。

## 2. 本地默认

- 服务默认只绑定 `127.0.0.1`；
- SQLite、上传和备份保存在明确的应用数据目录；
- API 不接受任意跨域来源；
- 原始截图默认只在本地 OCR；
- DeepSeek 只接收必要的结构化 Evidence Pack；
- 前端永远不保存供应商密钥；
- 诊断信息对个人字段做脱敏。

如用户主动绑定局域网地址，界面必须警告数据暴露风险。公网部署不属于本地配置选项。

## 3. 密钥与配置

- 密钥来自环境变量或本地受限配置；
- `.env`、数据库、上传、备份和日志不得提交 Git；
- 配置样例只使用占位值；
- 错误信息不得包含请求头、完整响应或密钥片段；
- 支持测试连接，但测试结果只显示模型、状态和脱敏错误；
- 密钥轮换后不需要重建数据库。

## 4. 上传安全

- 使用允许列表校验真实图片格式；
- 限制单文件大小、像素数、批次数量和总解码内存；
- 忽略用户文件名作为存储路径；
- 使用生成的 ID 和安全扩展名；
- 图像解码失败立即隔离；
- OCR 子进程或任务设置时间与资源上限；
- 不执行图片元数据或嵌入内容；
- 导出压缩包防止路径穿越。

## 5. 数据最小化

- 只采集研究需要的基金、金额、日期和交易字段；
- 不需要支付宝账号、实名、银行卡、身份证或密码；
- AI 请求不发送截图、账号标识或完整交易账本；
- 日志优先记录 ID、状态和计数，而非原文；
- 测试样例必须脱敏；
- 用户可选择清理已确认批次的原图。

## 6. 删除、备份与恢复

删除操作区分：

- 删除 OCR 草稿；
- 删除原始图片；
- 删除正式候选/持仓/交易；
- 删除整个本地数据集。

涉及正式数据的删除需要展示影响并二次确认。备份包含范围、创建时间、Schema 版本和校验和；恢复前先验证并保留可回退副本。

## 7. 外部服务

对每个外部 Provider 保存：

- 请求目的；
- 发送字段；
- 返回来源；
- 数据许可或使用限制；
- 超时、重试和缓存策略；
- 是否包含个人数据。

默认公开基金查询不携带个人数据。DeepSeek Provider 必须能完全关闭，关闭后确定性研究仍可使用。

## 8. 金融产品边界

- 产品明确标注“研究辅助，不构成收益保证或自动交易”；
- 操作状态是候选动作，最终决定由用户完成；
- 10% 回撤是参考，不是承诺；
- 报告展示数据截止日、未知项和失效条件；
- 不使用虚构“专家身份”增强权威感；
- 不基于用户实验资金之外的财务状况作结论；
- 不存储或代用户提交申购、赎回和转换指令。

## 9. 未来 C 端前置条件

公开部署前必须另行设计和验收：

- 身份认证、多因素验证和会话安全；
- 租户隔离与行级授权；
- 传输与静态加密；
- 对象存储与签名访问；
- 审计、限流、防滥用和告警；
- 数据导出、删除权和保留政策；
- 灾备和安全事件响应；
- 数据源许可、隐私政策和适用监管复核。

没有完成这些工作时，本地版不得通过端口转发直接变成 C 端服务。

## 10. 漏洞报告

公开仓库启用安全公告或私密漏洞报告后，README 应指向对应入口。安全问题不应在包含个人样例、密钥或可利用细节的公开 Issue 中披露。
